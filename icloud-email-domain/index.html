自定义iCloud邮箱域名

发表于 2021-10-16 分类于 技术 本文字数： 1.1k 阅读时长 ≈ 1 分钟

本文介绍如何给iCloud邮箱配置自定义域名，你可以使用foo@example.com收发邮件，而不是默认的foo@icloud.com

开始之前

Edit 20211016，这是iCloud beta功能，还没有在正式版iCloud发布。

该功能不对中国大陆地区Apple ID开放，笔者目前测试了美区Apple ID，其他区推测是一样的。如果你没有非中国大陆区的Apple ID，请修改ID的地区，或者注册一个新ID。美区Apple ID是最适合的，利用Clash打开全局模式代理，节点选择任何的美国节点即可，然后注册美区ID不需要提供信用卡或者手机号码。后续充值需求可以在淘宝上解决，很多家店都卖美区的gift card。

你需要有一个自己名下的域名，笔者的域名就是该博客的地址yangruoqi.site。后面，我们详细讲怎么在iCloud里这册yangruoqi.site，然后添加me@yangruoqi.site作为邮箱使用。

登陆icloud (Beta)

访问iCloud，登陆，自定义电子邮件>添加您拥有的域名。输入自己的域名，然后Apple会提供一串DNS信息，要求笔者在域名服务商登记这些信息，登记完成后，发送到该域名的邮件就会被转交Apple的iCloud邮件系统处理了，笔者可以在自己的iCloud邮箱里收到发给me@yangruoqi.site的邮件。你可以添加最多五个邮箱，如abc@yangruoqi.site……

Cloudflare DNS配置

笔者的域名托管在Cloudflare下，下面介绍如何在Cloudflare的DNS页面按Apple的要求设置。

除第二条CNAME记录是指向自己的博客地址，其他5条记录是Apple要求的DNS设置：一条CNAME记录，两条MX记录和两条TXT记录。TXT记录主要是作Apple的anti-spam用途的，两条MX记录最为重要，可以看到，邮件会被转交mx01和mx02两个iCloud邮件服务器处理。

DNS设置可能需要一些时间生效，耐心等待iCloud的界面通过检查，然后添加自己想要的以yangruoqi.site为域名的邮箱，最多五个。例如，可以用career@yangruoqi.site作为工作求职用的域名。自定义域名既可以收件也可以发件，你甚至可以设置自定义域名的邮箱作为iCloud应用的默认发件邮箱，spam@yangruoqi.site用来接受垃圾邮件。

总结

拥有一个自己域名的邮箱无疑是十分酷的，在沟通的时候更容易记忆，也展示了拥有者的技术能力，多个在自己域名下的邮箱也能进行分工，让工作和生活井井有条。
